Deep Link Security

Podatności deep linków

Interaktywne demo czterech ataków na deep linki w Androidzie. Wybierz atak po prawej, aby zobaczyć opis i uruchomić demo.

⚠️ Projekt edukacyjny. Nic nie jest wysyłane ani zapisywane.

Auth Bypass Open Redirect WebView XSS Deep Link Hijacking

Auth Bypass

Zwykły deep link victimapp://home
Atak: Auth Bypass victimapp://account

Ekran chronionego konta otwierany linkiem victimapp://account nie sprawdza sesji — pokazuje saldo i numer konta nawet po wylogowaniu.

Open Redirect

Nasza strona victimapp://redirect?url=https://deeplink-security-demo.vercel.app/
Atak: phishing victimapp://redirect?url=https://deeplink-security-demo.vercel.app/phishing-demo

Link victimapp://redirect?url=… przekazuje dowolny adres do przeglądarki bez walidacji — tak użytkownik trafia na podstawioną stronę logowania.

WebView XSS

Zwykłe imię victimapp://xss?name=Michał Kowalski
Atak: XSS victimapp://xss?name=<img src=x onerror="alert(document.getElementById('secret').textContent)">

Parametr name jest wstrzykiwany do lokalnej strony bez kodowania, więc skrypt z linku wykonuje się i odczytuje wrażliwe dane z WebView.

Deep Link Hijacking

Bezpiecznie: App Link https://deeplink-security-demo.vercel.app/secure
Podatny link (reset) victimapp://reset/confirm?token=DEMO_RESET_TOKEN_123

Złośliwa aplikacja rejestruje ten sam schemat victimapp://reset/confirm i po wybraniu jej z okna systemowego przechwytuje link wraz z tokenem.
